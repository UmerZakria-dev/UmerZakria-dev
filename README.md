## 🚀 Featured Projects

### 🖐️ [Gesture Recognition Live Using Custom Dataset](https://github.com/UmerZakria-dev/Gesture-Recognition-Live-Using-Custom-Dataset)
> **Real-time hand gesture recognition pipeline and live webcam inference powered by CNNs and MediaPipe.**

- **Architecture & Pipeline:** Built an end-to-end deep learning workflow with Convolutional Neural Networks (CNN) trained on custom dataset imagery.
- **Multiclass Classification:** Accurately classifies **36 alphanumeric categories** (`0-9` and `A-Z`) in real time from live video streams.
- **Key Technologies:** `Python`, `TensorFlow / Keras`, `MediaPipe`, `OpenCV`, `NumPy`, `Matplotlib`.
- **Artifacts:** Pre-trained baseline & optimized inference models (`gesture_model.keras`, `gesture_model_final.keras`).

[📂 View Repository](https://github.com/UmerZakria-dev/Gesture-Recognition-Live-Using-Custom-Dataset) • [📄 Explore Notebook](https://github.com/UmerZakria-dev/Gesture-Recognition-Live-Using-Custom-Dataset/blob/main/Gesture.ipynb)
